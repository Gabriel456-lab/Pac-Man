u# Pac-Man • • • ⍩⃝
## 🎮 Sobre o Projeto 
A proposta é recriar uma versão simples de um game famoso "Pac-Man", utilizando:
  > Estruturação com HTML |
  > Estilização com CSS |
  > Lógica de programação com JavaScript
  > Execução utilizando Node.js

## 🎯 Objetivo
Projeto desenvolvido para fins educacionais, com foco no aprendizado de desenvolvimento web e lógica de jogos.

🧾 Instruções de instalação e execução:

1.Baixe o projeto em .rar e depois extraía
2.Vá no local de instalação e abra com o Vscode.
3.Com o Vscode aberto, use o terminal e digite o comando "node index.js" e ele vai mandar um link pelo terminal, é só copiar e colar no navegador e jogar.
